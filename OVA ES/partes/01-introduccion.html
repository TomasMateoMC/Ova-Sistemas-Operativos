Parte 1

Introducción

Una de las funciones principales del sistema operativo es el control de todos los dispositivos de E/S (teclado, disco, impresora, red, etc.). Para lograrlo debe:

  • Enviar comandos a los dispositivos.
  • Detectar las interrupciones.
  • Controlar los errores.
  • Ofrecer una interfaz sencilla y, de preferencia, igual para todos los dispositivos.

El código de E/S es una parte importante del sistema operativo, y usar mal los dispositivos suele causar ineficiencias que bajan el rendimiento.

Resumen:

El sistema operativo actúa como intermediario entre el hardware y los programas, ocultando las diferencias físicas de cada dispositivo y presentando una interfaz uniforme.
